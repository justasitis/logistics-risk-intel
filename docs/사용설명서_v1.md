## 1. 소개

이 앱은 SK온의 물류 리스크를 한 화면에서 관리하는 웹앱입니다.

- 내 화물이 납기에 맞춰 오는지 (운송 이상·AIS)
- 선박이 리스크 영향권에 있는지 (지도·MI 이벤트)
- 월간 리드타임과 선사 정시성 (MI 리포트·지연 추이)

AI(Actify)는 정제·초안 작성까지만 하고, 게시와 승인은 사람이 결정합니다(HITL 원칙).

### 1.1 시작 방법

1. VDI에서 LogisticsRisk exe를 실행하면 백엔드가 기동되고 브라우저가 자동으로 없음니다 (`http://127.0.0.1:8000`).
2. 창을 닫으면 앱이 종료됩니다.
3. 트레이 아이콘(선택 사항)은 관심화물 알림을 10분 간격으로 확인합니다.

### 1.2 권한

| 구분 | 일반 사용자 | 지정 관리자 (so23132, so23364) |
|---|---|---|
| 대시보드, MI 리포트 조회, 지연 추이, 경로 조회 | 사용 가능 | 사용 가능 |
| 외부 MI 정제 탭 | 표시 안 됨 | 사용 가능 |
| 기준정보 탭 | 표시 안 됨 | 사용 가능 |
| MI 리포트 게시본 갱신·셀 편집 | 불가 | 가능 |

## 3. 운송 이상·AIS 탭

### 3.1 조회 시작

1. 상단의 법인 선택 드롭다운에서 법인을 고릅니다. 시작 시 '전체 법인'이 선택되어 있으며 데이터는 아직 없습니다.
2. 법인을 바꾸면 자동으로 조회됩니다. '전체 법인' 그대로 조회하려면 [새로고침] 버튼을 누르세요.
3. 조회에는 수십 초~수 분이 걸릴 수 있습니다.

### 3.2 지도

- 항로 라인(색상 = 위험도), 항만 포인트, AIS 선박(운송과 매칭된 활성 선박만), MI 영향권 원이 표시됩니다.
- 오른쪽 아래 +/− 버튼으로 확대·축소합니다.
- 오른쪽 위 카운터 아래의 '레지스트리 영향권 ON/OFF'로 추적 중 이벤트 영향권을 켜고 끌 수 있습니다.
- 일정 이상 화물 목록에서 HBL 카드를 선택하면, 연결된 선박이 지도에 있을 때 지도가 그 선박으로 부드럽게 이동합니다.

> [화면 삽입 위치] 지도 전체 (항로+AIS+영향권) — `images/02_dashboard_map.png`

### 3.3 일정 이상 화물 목록 (마스터-디테일)

- 검색창에서 HBL, 운송번호, 선박명, **PO 번호**, 공급업체, 품목으로 검색할 수 있습니다.
- 카드를 선택하면 오른쪽에 상세가 없음니다. 요약에는 HBL, B-LAP, 법인/Plant, Route, Vessel, Voyage, PO, Item, ETD, ETA 순으로 표시됩니다.
- 하위 탭:
  - **Timeline**: ETD/ETA 변경 이력. 날짜 변경이 실제로 있었는지, 얼마나 바뀌었는지 보여줍니다.
  - **MI 영향**: 이 화물에 영향을 주는 승인 MI 이벤트. 카드 아래 '연관기사 클릭'으로 원문 기사를 새 탭에서 없음수 있습니다.
  - **원인 후보**: 지연 원인 후보 분석.

> [화면 삽입 위치] 마스터-디테일 + Timeline — `images/03_master_detail.png`

### 3.4 관심화물(watchlist)과 알림

- 관심 화물로 등록하면 상태 변화 시 알림 센터와 트레이로 알림이 옵니다.

## 4. 외부 MI 정제 탭 (관리자)

외부에서 수집한 물류 뉴스 후보를 AI가 정제하고, 사람이 승인하는 화면입니다.

1. **후보 반입**: SharePoint의 일자별 후보 파일을 불러옵니다.
2. **Actify 정제**: 후보를 이벤트로 정제합니다.
3. **검토·승인**: 이벤트별로 승인/수정/반려. 위치가 미해결이면 드롭다운에서 위치 마스터와 매칭하세요 (예: 중국 연안 → CN_COAST_EAST 등).
4. 승인된 이벤트는 대시보드 지도와 MI 리포트에 반영됩니다.

> [화면 삽입 위치] 검토·승인 화면 — `images/04_mi_review.png`

## 5. MMSI 관리 탭

선박명–MMSI 매핑을 관리합니다. 선박은 법인 구분 없이 관리됩니다.

1. [선박 목록 조회] 버튼을 누륩니다 (전체 법인의 활성 운송 기준).
2. 미등록/등록/AIS 감지/전체 탭으로 상태별 필터링합니다.
3. MMSI(9자리 숫자)를 입력하고 [저장]. CSV/JSON 가져오기·낮추기도 가능합니다.
4. 선박명 끝의 항차번호(예: "PACIFIC SINGAPORE 2639W"의 2639W)는 자동으로 제거되어 매칭됩니다.

## 6. MI 리포트 탭

월간 물류 리포트입니다. 구성: 헤드라인(금월 핵심 변동), 권역별 리드타임 표, 물류 이벤트 지도, 인사이트, 시황 차트.

### 6.1 권한에 따른 보기

- 일반 사용자: 마지막으로 게시된 **게시본**을 봅니다 (집계 없이 즉시 표시).
- 관리자: 아래 작업 흐름을 사용할 수 있습니다.

### 6.2 관리자 작업 흐름 (권장 순서)

1. **[새로고침]**: 리드타임을 라이브로 재집계합니다 (수 분 소요). 화면이 '라이브 재집계 결과 — 게시본 미반영' 배너로 바뀝니다. 이 상태는 아직 다른 사람에게 보이지 않습니다.
2. **셀 편집** (필요 시): 리드타임 표의 셀을 수기 수정하고 [편집값 저장]. 재집계 결과에 반영됩니다.
3. **인사이트 초안 생성**: Actify가 핵심 변화·권역 동향·익월 체크 포인트 초안을 작성합니다. 섹션별로 편집한 뒤 [편집본 저장].
4. **[게시본 갱신]**: 재집계된 리드타임 + 저장된 인사이트 편집본을 SharePoint에 게시합니다. 이 시점부터 전원이 새 게시본을 봅니다.

### 6.3 리드타임 표 읽기

- 권역(유럽/미주/아시아)별 그룹, 월별 Avg/Min/Max. 예상 없음 회색.
- 유럽 해상은 수에즈/희망봉 경유로 구분됩니다 (stopby 정보 우선, 없으면 선사·선박 규칙으로 추론).
- 아시아의 북중국(훼리) 행은 인천훼리터미널 도착 건의 실측입니다.
- 해상 표는 운송모드 해상(100)만 집계합니다.
- 그룹 헤더의 Gap 배지: 최근 주 ETA 대비 실제 도착 차이 (정상/주의/경고).

### 6.4 물류 이벤트 지도

- 승인된 MI 이벤트의 영향권이 표시됩니다. 권역 포커스 버튼(전체/유럽·수에즈/지중해/미주 동안/미주 서안/아시아)으로 범위를 좁힐 수 있습니다.
- 팝업은 기본 표시되며 드래그로 옮길 수 있습니다. 화살표는 자동으로 따라옵니다.
- 팝업의 '연관기사 클릭'으로 원문 기사를 없음수 있습니다 (기사 링크가 있는 이벤트만).

> [화면 삽입 위치] 이벤트 지도 팝업 — `images/05_report_map_popup.png`

### 6.5 출력

- [HTML 출력]: 현재 화면(게시본) 그대로 HTML 파일로 저장 — 메일 첨부·공유용.
- [인쇄]: 인쇄 미리보기.

## 7. 지연 추이 탭

도착지연을 원인별로 분해하고 선사별 정시성을 비교합니다.

### 7.1 조회

1. 항로 그룹과 기간(6/12개월)을 고르고 [조회]를 누릅니다.
2. 항로 그룹: 아드리아해(수에즈/희망봉), 북유럽·지중해, 미주 동안/서안, 중국→한국.

### 7.2 블록 A — 지연 분해

- 입항 누적지연 = 출항지연 + 항해 증감. 막대가 두 조각으로 갈라지는 애니메이션으로 보여줍니다.
- 붉은색 = 출항지연(물류팀·포워더 대응), 파란색 = 항해 증감(선사 대응).

### 7.3 블록 B — 선사 정시성 탄착군

- 점 하나 = 항차 한 건의 항해 증감(일). 0 기준선이 계획대로 항해.
- **P50(중앙값)**: 선사의 '보통' 항해 증감 / **IQR**: 가욋50% 폭 — 좁을수록 계획 가능 / **P90 초과 점(붉은색)**: 가끔 크게 터지는 항차.
- 표본 10항차 미만은 '판정 보류'로 표시됩니다.
- 선사별 판정문은 규칙 기반 자동 생성입니다 (예: "늘 늦지만 꾸준히 늦습니다. N일 당겨 잡으면 해결됩니다.").
- [항차 발사] 버튼으로 착탄 애니메이션을 다시 봅니다.

> [화면 삽입 위치] 탄착군 (GIF 권장) — `images/06_delay_strip.png`

### 7.4 읽을 때 주의 (화면 하단 고지와 동일)

- 환적 구간 분리는 하지 않습니다. 내륙 구간은 별도 집계입니다.
- 시장 정시성 지표(Sea-Intelligence 등)와 정의가 달라 직접 비교할 수 없습니다.
- 원본이 날짜 단위면 IQR이 0으로 나올 수 있습니다(측정 해상도 한계).

## 8. 경로 조회 탭

운송 경로 마스터를 조건 조회합니다.

1. 구분조건(법인/사업장/물류사/사업구분/운송모드/출발지/최종사이트)을 고르고 기간을 지정한 뒤 조회합니다.
2. 없음머리의 필터로 결과를 좁힐 수 있습니다.
3. CSV 다운로드(엑셀 호환, BOM 포함)를 제공합니다.
4. 리드타임·지연 추이에서 안 잡히는 구간이 있으면 이 탭에서 dprt/arvl/stopby 값을 확인해 관리자에게 알려주세요.

## 9. 기준정보 탭 (관리자)

앱의 기준 데이터를 화면에서 수정합니다. 저장 즉시 서버에 반영되며, 각 화면은 다음 조회부터 적용됩니다.

| 섹션 | 내용 |
|---|---|
| 항로 그룹 | 리드타임·지연 추이의 항로 정의 (도착항 코드, 경유 키워드, 행 구분) |
| MI 위치 마스터 | MI 이벤트 위치 코드·좌표·반경·별칭 |
| 지연 판정 임계값 | 탄착군 판정문 기준 (IQR, 표본 수 등) |
| Gap 경고 임계값 | 지연 추이 경고 기준 (기본 5일/3주) |
| 이상탐지 임계값 | 대시보드 이상탐지 기준 |
| 법인 | 법인 코드·B-LAP 코드 매핑 |
| 선사 추론 규칙 | 선박명→선사·경유항로 추론 규칙 |

- 저장 시 유효성 검사를 통과해야 반영됩니다.
- [기본값으로 되돌리기]로 언제든 초기 상태로 복원할 수 있습니다.

- 트레이 아이콘이 관심화물 알림을 10분마다 확인하고, 새 알림만 토스트로 표시합니다.

## 11. 문제가 보일 때

| 증상 | 확인할 것 |
|---|---|
| 탭이 안 보임 (외부 MI 정제·기준정보) | 지정 관리자 계정이 아니면 숨겨집니다 |
| 지도 선박이 안 보임 | AIS 파일(SharePoint Marinesia) 반영 여부, 운송과 매칭된 선박만 표시됨 |
| MI 리포트가 오래돼 보임 | 게시본은 관리자가 갱신한 시점의 데이터입니다. 배너의 게시 일시를 확인 |
| 애니메이션이 안 움직임 | Windows 설정 > 접근성 > 시각 효과 > '애니메이션 효과'가 꺼져 있으면 자동으로 정적 표시됩니다 |
| 숫자가 수기 리포트와 다름 | 경로 조회 탭에서 해당 구간의 코드를 확인해 관리자에게 전달 |
